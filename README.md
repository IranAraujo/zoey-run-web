# 🐾 Zoey Run! — Versão Web & Mobile

Jogo 3D Runner acrobático da Fox Paulistinha Zoey, otimizado para navegadores Web (PC e Celular) usando Godot 4.7.2 (WebGL2 / GL Compatibility).

### 🎮 Jogue Agora no Navegador:
👉 **[https://iranaraujo.github.io/zoey-run-web/](https://iranaraujo.github.io/zoey-run-web/)**

---

### 🕹️ Controles:
* **💻 No Computador:**
  * `A` / `D` ou `◀` / `▶`: Mudar de Faixa & Drift Turbo
  * `Espaço` / `W`: Pular & Bote Aéreo na Mosca
  * `S`: Abaixar (Slide)
  * `E` ou Clique Esquerdo: Latir
  * `Q` ou Clique Direito: Super Latido Dourado
  * `ESC`: Pausa
  * `⛶`: Tela Cheia
* **📱 No Celular:**
  * Use os botões virtuais na tela (`◀`, `▶`, `⬆️ Pular`, `⬇️ Slide`, `🐕 Latir`, `⚡ Super`)
  * Ou use gestos de deslize (swipe) na tela!
  * Gire o celular para a horizontal para melhor visão!
